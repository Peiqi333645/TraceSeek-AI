# 寻迹AI助手：本次定制更新

## 用户界面

- 全面升级黄色视觉系统，采用更克制的暖金色、柔和阴影、渐变按钮和分层卡片。
- 设置页改为新手模式，只保留账号、可选 AI、自定义刷新时间、接收邮箱和提醒开关。
- AI 由用户填写自己的 DeepSeek、豆包、通义千问或兼容接口，不再提供充值、余额或次数计费入口。
- SMTP 专业参数、访问节奏参数及平台网址继续由系统内部配置，不向普通用户展示。
- 保留红色“立即运行”、绿色运行进度与明确的成功状态。

## 响应速度

- 登录二维码页面的固定等待由约5秒缩短到约0.7秒。
- 扫码及登录确认检测由约1.2秒缩短到约0.5秒。
- 设置页不再请求外部计费服务器，打开速度更稳定。
- 操作状态刷新由4秒提升到2.5秒；点击立即运行后界面立即反馈。
- 本地服务启动检测由0.5秒缩短到0.08秒。

## 退出登录修复

- 退出时同时删除登录状态和头像缓存。
- 退出操作会作废仍在运行的扫码线程，避免旧线程重新写回账号。
- 抓取过程中退出会写入退出标记，旧浏览器会话结束时不能恢复已经删除的登录状态。

## 说明

推荐与收藏的刷新分钟数仍然完全由用户自定义。本次优化针对应用启动、界面交互和登录操作，不会擅自改变用户的监控周期。
